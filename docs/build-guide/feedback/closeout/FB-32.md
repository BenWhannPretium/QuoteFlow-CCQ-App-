- **A. The map.** `packages/domain/src/intake/sf-prefill.ts`: `PREFILL_MAP` (`{ quoteflowField, sfSource, kind: 'fill' | 'suggest', match }`), `sfFillsFor`, `sfPrefillOf`, `sfSuggestionsFor`, and the two matchers. `prefillFromOpportunity` and `itemFromSpec` read it; the logic that sat in both is gone. `matchCode` moved into the module as `matchCodeLoose` (unchanged rule, so resin matches as before) beside the new `matchCodeExact`. `match` gained `number` (annual volume) beside `text`, `neck` and `valueList:<key>`. A characterization test copies the pre-FB-32 rules and compares them with the map on seven specifications, one test per field (resin, neck, volume, container size, item name).
- **B. Item 1's name** is the first specification's `Name`, else its `Capacity__c`, cut to 120, only while the KAM has typed none. It is tagged "from Salesforce" with the usual undo (`sfPrefill.label`, one new optional key in `packages/contracts/src/intake.ts`). Re-picking an opportunity never overwrites a typed name; the name Salesforce itself supplied last time is replaced by the new opportunity's (and cleared when the new one has none). Items added from "Add from Salesforce products" now carry the same tag on their name. **Considered and not done:** product family, market, sub-market, PCR %, additive, dimensions, gram weight, mold, packaging, dates (no confirmed meaning or no exact list match; see the candidates list); `Product_Type__c` and `Opportunity.Quote_Type__c` for the request class (a guess).
- **C. Suggestions** are shown only while `intake_sf_suggestions_enabled` is true, for an exact match (case-insensitive, trimmed, on the entry's code or label; the stricter `matchCodeExact`, which also never matches a `freeText` entry such as "Custom color"), never fill by themselves, and are labelled with Salesforce's own field label ("Color in Salesforce says “Natural”. Use this"). "Use this" fills the color, clears the Custom description and tags it (`sfPrefill.colorType`); after that it is an ordinary "from Salesforce" value with the undo. A color the resin does not offer (a stock color) is not suggested.
  - **What the describe showed** (read-only, on 2026-11-19; no record was read): `Opportunity_Product_Specifications__c.Color__c`, label "Color", text 255. `Product_Type__c`, label "Product Type", picklist of Competitive, Non-Stock, NPD, RFP, Stock, Stock Plus, Stock Plus Extended: **a kind of quote, not a bottle family, so no hint under Product family**. `Finished_Good_Type__c` (label "Finished Good Type", text 60) exists on the specification and on `Product2`; it is not mapped (values unknown).
  - **Recommendation:** keep the setting off until Zachary confirms `Color__c` is the product's colour; then it can go on for UAT. `Finished_Good_Type__c`, not `Product_Type__c`, is the better candidate for Product family.
